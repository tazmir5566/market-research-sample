# Criteria and Methodology

## Target criteria

| # | Criterion | Requirement |
| --- | --- | --- |
| 1 | Segment | SMB HR and payroll software |
| 2 | Geography | Headquartered in the United States or Canada |
| 3 | Size | 50–499 employees |
| 4 | Integrations | Public integration marketplace or partner program |

## Size categories

| Category | Employees |
| --- | --- |
| Micro | Under 50 |
| Small | 50–99 |
| Mid-size | 100–499 |
| Large | 500 and above |

## Fit rules

| Assessment | Rule |
| --- | --- |
| Strong fit | Meets all four criteria |
| Possible fit | Meets geography and size, but is in an adjacent segment or has no listed integration marketplace |
| Not a fit | Outside the target geography or size range, or in an unrelated segment |

## Process

1. Agree the business question and the criteria above.
2. Build the company list and record segment, location, size and main product.
3. Check each company against the four criteria.
4. Assign a fit level and write the reason in one sentence.
5. Add notes on anything that needs confirming before outreach.

In real projects, each detail would come from a named source (company website, LinkedIn company page, data tools) with a check date. In this sample, all details are invented.
